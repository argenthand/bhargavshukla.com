# bhargavshukla.com

A personal site: long-form writing, short code snippets, and a resume.

## Language

**Post**:
A long-form piece of writing published on the site.
_Avoid_: Article, blog post, essay

**Writing**:
The section of the site that lists every Post.
_Avoid_: Blog, articles

**Book Review**:
A Post in the Books Category that reviews a single book.
_Avoid_: Book note, reading log

**Snippet**:
A small reusable piece of code with a short explanation, shown only in the Snippets list, never on a page of its own.
_Avoid_: Gist, TIL, note

**Summary**:
A one-to-two sentence description of a Post, shown in lists and link previews.
_Avoid_: Excerpt, description, blurb

**Category**:
The single subject grouping a Post or Snippet belongs to; one shared set across the site.
_Avoid_: Topic, section, tag

**Updated Date**:
The date a Post or Snippet's content last meaningfully changed, set by hand; shown only when later than the publish date.
_Avoid_: Modified date, last edited

**Draft**:
A Post or Snippet that is still being written and is not visible to visitors.
_Avoid_: Unpublished, hidden, private

**Publish Date**:
The calendar date (no time) a Post or Snippet goes live, read in the America/Toronto timezone.
_Avoid_: Post date, go-live date

**Scheduled**:
A finished Post or Snippet whose Publish Date is in the future; it becomes visible on that date.
_Avoid_: Queued, pending, embargoed

**Featured**:
A mark on a Post that promotes it on the homepage.
_Avoid_: Pinned, highlighted, starred

**Recommended Post**:
One of 1–3 other Posts suggested as next reading at the end of a Post.
_Avoid_: Related post, suggested post, "read next"

**Resume**:
The page summarizing work history and skills; for now it is the entire portfolio.
_Avoid_: CV, portfolio, about
